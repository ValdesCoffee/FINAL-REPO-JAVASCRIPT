### 🧠 Main Variables or functions
* Use of **innerHTML**: This is DOM manipulation, if you need change something in the `<div>app</div>`, you need this for rewrite.
* Use of **addEventListener**: This is DOM manipulation, if you need listen a object on the HTML this is a tool for make a click, listen boolean options.
* Use of **emailValue**: it's a const that a i create with the atribute value, that evalue the value of the email.
for example
`const emailValue = emailInput.value.trim();C
* Use of **passwordValue**: it's a const that a i create with the atribute value, that evalue the value of the password.
for example
    `const passwordValue = passwordInput.value.trim();`
